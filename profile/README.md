<h1 align="center">Wellyard</h1>

<p align="center"><b>Split apart. Seen whole.</b><br>拆得开，看得全。</p>

https://github.com/user-attachments/assets/7d015494-dc24-44fa-9136-73c3713c6cf1

Wellyard is a [Claude Code](https://claude.com/claude-code) plugin that sets up a product as **one main repo plus one repo per code base**.

- **See the whole product.** The main repo holds the requirements, the decisions and the list of components, with every code base cloned under it. Start your AI there and it sees all of it.
- **Keep every code base its own.** The web app, the backend and the mobile app each get a repo, with their own history and their own visibility.
- **Bring old projects in safely.** Wellyard reads an existing project without touching it, writes a migration plan, and moves nothing until you approve the plan.

> The plugin repo goes public soon. Wellyard speaks English and 简体中文.

<summary>中文</summary>

Wellyard 是一个 Claude Code 插件：把一个产品搭成「一个主仓库，加每套代码一个仓库」。

- **看得全。** 需求、决定和组件清单放在主仓库，每套代码克隆在它下面。在那里启动 AI，它就能看到整个产品。
- **拆得开。** 网页、后台、App 各是一个仓库，各有各的历史，公开还是私有各自定。
- **老项目稳着迁。** Wellyard 只读不改地分析老项目，写出迁移方案，你确认之前什么都不动。

> 插件仓库即将公开。Wellyard 说简体中文和英文。
