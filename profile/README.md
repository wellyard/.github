<h1 align="center">Wellyard</h1>

<p align="center"><b>拆得开，看得全。</b><br>Split apart. Seen whole.</p>

Wellyard 是一个 Agent Skill：把一个产品搭成「主仓库 + 每个端一个仓库」。需求、接口和决定放在主仓库，你和 AI 打开它就能看到整个产品；老项目先出迁移方案，你确认后再迁。

Wellyard is an agent skill that sets up a product as one main repo plus one repo per codebase, and moves existing projects in once you approve the plan.
